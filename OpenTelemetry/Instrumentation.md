# Instrumentation

- **Instrumentation** is the process of adding code to your application so it can emit telemetry data - like traces, metrics and logs- Which is essential for observability. There are 2 type of instrumentation.
  - Code based
  - Zero code based
- **Code based** : Code Based solutions allows you to get deeper insight and rich telemetry from your application itself. They let you use the OpenTelemetry API to generate telemetry from your application.
- **Zero Code based** : When you can't modify the the code then you can use Zero code based telemetry. they provide rich telemetry from library you use.
